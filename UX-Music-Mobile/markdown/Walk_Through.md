# 操作説明: Walkman Cross UI

## 基本操作
画面中央の再生画面を起点に、画面全体をスワイプして移動する。

- 右へスワイプ: 左側の **再生キュー** へ移動
- 左へスワイプ: 右側の **お気に入り** へ移動
- 下へスワイプ: 上側の **ライブラリ** へ移動
- 上へスワイプ: 下側の **設定** へ移動

外側の画面では、中央へ戻る方向へスワイプすると再生画面に戻る。
外側の画面で対応しない方向へスワイプしても、その画面に留まる。

## 各画面
- **再生画面（中央）**: ジャケット・曲名・アーティスト・進捗バー・トランスポート（前/再生・停止/次）。
  上部のボタンから歌詞表示とお気に入り登録ができる。背景はアルバムアートに沿った青緑系グラデーション。
- **再生キュー（左）**: 現在の再生キュー。行をタップするとその曲へジャンプして再生する。
- **お気に入り（右）**: お気に入り登録した曲。タップで再生、左スワイプで解除。
- **ライブラリ（上）**: ダウンロード済みのアルバム / プレイリスト / 全曲。項目をタップして一覧・詳細へ。
- **設定（下）**: イコライザー（プリセット・プリアンプ・10 バンド調整）と、サーバー設定 / QR ペアリング /
  プレイリスト取り込み / Remote ライブラリ / Remote コントロールへの入口。

## 再生中表示
再生画面以外では、画面下部にネイティブ bottom toolbar として現在の曲（ジャケット・曲名・アーティスト）と
再生 / 次へ操作を暗色で表示する。

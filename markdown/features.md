# 機能一覧 (Features)

UX Music が現在提供している、または計画中の主な機能です。

## 基本的な機能

* **ライブラリ管理**: ローカルの音楽ファイル（mp3, flac, m4a, wav, ogg）をスキャンし、ライブラリとして管理。
* **多彩なビュー**: ライブラリ、アルバム、アーティスト、プレイリスト、最近追加した曲など、様々な表示モード。
* **再生機能**: 標準的な再生、一時停止、次へ、前へ、シーク、音量調整。
* **イコライザー**: 10バンドのグラフィックEQとプリセット機能。
* **リピート・シャッフル**: キュー全体のリピート、1曲リピート、シャッフル再生。
* **再生キュー管理**: 次に再生する曲のリストを管理・編集。
* **プレイリスト**: 自由なプレイリストの作成、曲の追加・削除。
* **iOS コンパニオン（Wear 連携）**: 同一 LAN 上のデスクトップからライブラリ取得・原音ダウンロード。ダウンロード済み曲向けに、端末内永続のローカルプレイリスト（作成・削除・名前変更・曲の追加/削除・プレイリスト順および曲順の並び替え）を提供（デスクトップの `.m3u8` とは別ストア）。
* **UX Sync（基盤実装中）**: 同一 LAN 上で mDNS / Bonjour により UX Music 端末を自動発見し、UX Sync 専用設定画面から到達可能URLと複数NIC候補を確認できる。mDNS が不安定な Windows 側では、ペアリング時に実通信した相手を既知 peer として保存し、発見一覧へ補完する。発見 peer には6桁コード確認つきペアリングを UI から開始・確定でき、画面を閉じても保存済みペア端末を復元できる。同期専用トークンで子側再生イベントを親へプッシュでき、ローカル再生回数イベント、`LibraryHost` からの未取得音源、既に同期済み曲の不足ジャケットは接続可能なペア済み端末へ定期的に自動同期される。音源の自動取得は `syncCachePolicy` により、全曲ミラーまたは最近再生＋キュー先読みの selective キャッシュを選べる。`syncPreferredFormat` により pull 側でも原本または MP3 320kbps を選べ、対応 peer からの自動同期・タップDL・prefetch は MP3 320kbps で保存できる。selective では空き容量閾値を下回ると最終アクセスが古い同期取得音源を LRU 削除し、catalog から再び remote 曲として表示できる。音源転送 MVP として、親の既存ライブラリ原本を `/sync/library/snapshot` と `/sync/assets/{trackId}/file` から取得し、子側の `SyncLibrary` へ取り込める。さらに LibraryHost の snapshot metadata を `sync-remote-catalog` にキャッシュし、未取得のリモート曲も統一ライブラリビューへ `DL可能` として表示できる。`DL可能` な曲は再生操作時に取得元 peer から対象曲だけをダウンロードし、完了後にローカル曲として自動再生できる。ジャケットは `/sync/assets/{trackId}/artwork` で別アセットとして取得する。逆方向の push 転送として `/sync/library/import` によりこちらの音源、表示メタデータ、ジャケット、再生回数をペア済み端末へ送れ、FLAC などの重い音源は MP3 320kbps へ変換しながら転送できる。受信側は保存済み音源を再スキャンして不足タグや埋め込みジャケットを補完する。保存先ボリュームの空き容量が設定値を下回る場合は、自動同期・音源取得・音源受信を停止する。`/sync/identity` と `/sync/schema` で protocol/schema/capability を自己申告し、将来のバージョン差に備えたネゴシエーションを行う。自動同期が走った時は右下トーストで取得数、既存数、再生回数、ジャケット数を確認できる。UX Sync 専用設定画面の `同期` タブからペア済み相手端末を選び、1曲取得・全曲取得・1曲転送・全曲転送を実行でき、転送中はファイル名・件数・転送量・転送速度を確認できる。Windows 検証用に、SSH から GUI を起動せず `--sync-reset-test-data` / `--sync-pair` / `--sync-auto-once` / `--sync-pull-one` / `--sync-pull` も実行できる。
* **アートワーク表示**: 埋め込みアートワークの抽出と表示（`safe-artwork://` プロトコルによる安全な表示）。
* **ラウドネス解析**: EBU R128 に基づくラウドネス値の解析（再生時の音量平準化のため）。
* **歌詞表示/編集**: `.lrc` 同期歌詞の表示に加え、LRCエディタでタイムライン編集（中央移動・左右端リサイズ・ルーラー倍率変更）と既存LRC再編集に対応。
* **TXT自動同期解析 (Swift + CoreML / Python fallback)**: LRCエディタから、TXT歌詞を自動時刻同期。macOS では `Swift sidecar` が `WhisperKit` / CoreML を優先利用し、`Demucs` / 埋め込み整列も段階的に Swift 移植する。Windows など非 macOS 環境では既存 `Python sidecar` をフォールバックとして利用し、JSON 契約と UI 導線は共通化する。
* **右サイドバー映像プレビュー**: `mp4` など映像付きローカル楽曲は、右サイドバーのジャケット領域を `16:9` で映像表示（Wailsでは `/safe-media/` 経由のミュート映像プレビューを再生状態へ同期）。
* **Discord RPC**: 現在再生中の曲を Discord のステータスに表示。

## ユニークな機能

* **CDリッピング (UX Rip)**: オーディオCDから高品質に吸い出し、MusicBrainzから情報を自動取得。
* **MTP転送 (UX MTP)**: WalkmanなどのMTPデバイスへmacOSから直接転送。
* **YouTube ダウンロード**: YouTube の動画やプレイリストの URL から直接ライブラリに楽曲を追加。字幕がある動画は同期歌詞（`.lrc`）も自動生成。「ライブラリを管理」ボタンの連打から機能有効化に対応し、Wails環境ではアプリ内モーダルで同意確認。字幕候補の選択UIと詳細コンソールログに対応。
* **シチュエーション別プレイリスト**: 「朝」「夜」「雨の日」など、曲の解析データに基づき自動生成。
* **再生履歴プレイリスト**: 「よく聴く曲」「最近あまり聴いていない曲」などを自動生成。
* **イントロクイズ**: ライブラリの曲を使ったイントロクイズ機能。
* **ラウドネスノーマライゼーション**: 曲ごとの音量差を平準化（EBU R128準拠）。
* **Light Flightモード**: CPU/メモリ負荷を極限まで抑えた超軽量動作モード。
